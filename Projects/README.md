## Final Objective

Reach a point where writing Java code feels automatic and you no longer need to search for:

- How to iterate an ArrayList
- How to use a HashMap
- How to sort an array
- How to write loops
- How to manipulate Strings

Once syntax becomes automatic, all attention can go toward algorithms and problem-solving.
